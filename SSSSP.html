Encodeur / Décodeur de SSSS+

Encode et décode du texte Unicode avec une clé déterminant directement les décalages utilisés par le système.

Pas de bibliothèques externes · Fonctionne sans internet
La clé détermine directement les décalages Unicode. Elle n'est jamais enregistrée dans le texte encodé.
Text is processed as Unicode before encoding.
Structure : base64 du texte Unicode transformé par la clé. Aucun élément de la clé n'est inclus dans le payload.
